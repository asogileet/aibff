# AR 雙手食指追蹤與人偶同步互動規格文件 (AR Dual Hand Index Finger Tracking Spec)

## 1. 需求背景與設計目標

在目前版本的 AR 視訊模式（Webcam Passthrough）中，先前的關節人偶模式（Puppet Mode）暫時採用滑鼠/單點觸控 fallback，尚未完全啟用鏡頭手勢實時辨識。

使用者提出明確需求：
> 「AR mode的偵測動作，可以補上了，可以偵測食指就好，兩隻手的食指變成一起動」

### 核心目標：
1. **補齊 AR 模式鏡頭手勢偵測**：當使用者在 AR 模式中開啟鏡頭與人偶玩偶互動時，啟動高效輕量之手勢追蹤引擎。
2. **精簡至雙手「食指（Index Finger）」**：無需複雜的 21 關節全手部姿態分析，專注於提取兩隻手的食指指尖（Landmark 8），降低計算負擔並大幅提高追蹤穩定度與畫面順暢度。
3. **兩隻手食指同步動作（Dual Index Multi-Tracking）**：
   - 支援同時追蹤使用者的「左手食指」與「右手食指」。
   - 畫面上呈現兩枚獨立的食指標記指針（左指與右指，以不同科技光暈標識）。
   - 兩隻手的食指可同時吸附並拉扯人偶的不同肢體（例如：左食指拉動人偶右手，右食指拉動人偶左手，雙指同時外展讓人偶張開雙臂；或是單指摸頭、另一指拉動手臂）。

## 3. 詳細功能規格 (Detailed Specifications)

### 3.1 雙手食指辨識與座標映射 (HandTracker.js)
1. **模型配置**：
   - 整合輕量版 MediaPipe Hands WebAssembly 引擎。
   - `maxNumHands: 2`（開啟雙手偵測模式）。
   - `modelComplexity: 0` 或 `1`（優先平衡效能與偵測精度，確保 30~60 FPS）。
   - `minDetectionConfidence: 0.5`，`minTrackingConfidence: 0.5`。
2. **食指特徵點抽取**：
   - 針對檢測出的每一隻手（最多 2 隻）：
     - 食指指尖（Landmark 8: `INDEX_FINGER_TIP`）。
     - 拇指指尖（Landmark 4: `THUMB_TIP`，作為捏合距離參考）。
     - 手腕（Landmark 0: `WRIST`，作為手部比例尺度基準）。
3. **座標鏡像校正**：
   - 因視訊畫面開啟鏡像（Mirroring），食指 X 座標轉換為：
     $$X_{screen} = (1 - landmark.x) \times WindowWidth$$
     $$Y_{screen} = landmark.y \times WindowHeight$$
4. **抓取 / 碰觸觸發判定 (Trigger Options)**：
   - **方式 A（捏合模式 Pinch）**：計算食指與拇指歐幾里得距離，當小於手掌尺度的閥值（例如距離 `< 0.07` 或 相對比例 `< 0.6`）時判定為捏取（`isPinching = true`）。
   - **方式 B（食指接觸模式 Proximity Tap）**：食指指尖進入人偶關節投影半徑（`< 45px`）並停留超過 150ms 即自動吸附並進入拖曳狀態。
   - **混和自適應**：預設只要食指捏合或靠近點擊即開始拖曳，使用者放開食指或移開即維持擺姿或彈回。

### 3.2 雙食指同時動作與物理求解 (PuppetController.js)
1. **多指標狀態架構 (Multi-Pointer State)**：
   - 擴充原本單一的 `fingerScreenPos`、`grabbedJointKey` 為支援多點：
     - `pointers = Map<pointerId, { x, y, isPinching, grabbedJointKey, startFinger, startBoneRot }>`。
     - 支援 `pointer_0`（第一隻手/左食指）與 `pointer_1`（第二隻手/右食指）。
     - 同時保留滑鼠與單點觸控作為 `pointer_mouse`，確保向下相容性。
2. **雙手獨立關節鎖定**：
   - 左右食指可分別鎖定不同的肢體關節。
   - 例如：
     - 指標 A 抓住 `leftHand`（人偶左手），指標 B 抓住 `rightHand`（人偶右手）。
     - 當兩隻食指同時向上提或向外拉時，左右手臂骨架同時由各自的 Two-Bone IK 求解，呈現雙臂展開或高舉姿態。
     - 若一隻食指抓 `head`、另一隻食指抓 `hips`，則可同時調整頭部角度與身體高度！
3. **互斥保護機制**：
   - 同一個關節節點同一時間僅允許一個食指鎖定抓取，避免兩個指標拉扯同一骨骼產生數值震盪。

### 3.3 雙手視覺指針與回饋 (PuppetVisualizer.js)
1. **雙食指色彩辨識**：
   - **第一隻手 (Hand 1 / 主食指)**：青藍色／翠綠色光環（Cyan/Emerald Glow），顯示「食指 1」。
   - **第二隻手 (Hand 2 / 次食指)**：甜美粉／紫羅蘭光環（Pink/Violet Glow），顯示「食指 2」。
2. **雙引力彈簧虛線 (Dual Tension Lines)**：
   - 當雙手同時抓取關節時，各自從食指位置拉出帶有動態波紋的虛線彈簧，連接至被抓取的關節。
3. **語音與對話回饋**：
   - 當兩隻手同時抓取人偶兩側（如雙手或摸頭+拉手）時，觸發雙手互動專屬台詞：
     - 「哇～主人的兩隻手都在拉我耶，是要抱抱嗎？🥰」
     - 「兩邊一起動～好厲害的操偶技巧呀！✨」

### 3.4 降級與離線安全性 (Graceful Fallback)
1. 若網路環境無法自 CDN 取得 MediaPipe 腳本，系統自動維持滑鼠/觸控單點模式，不拋出任何中斷執行的例外。
2. 控制影像串流處理頻率（預設每 33ms 執行一次檢測，約 30 FPS），避免高解析度視訊過度佔用 CPU/GPU 資源。
