👀 眼睛視線與頭部追蹤同向修復展示

在此區域內滑動滑鼠，可即時比對「當前反向問題」與「修正後同向注視」的眼球及頭部連動差異

🖱️ 請在此框內自由移動滑鼠測試
現況（反向錯誤）
targetX = -mouse.x * 0.8
yaw = -mouse.x * 0.35
pitch = mouse.y * 0.25
修復後（正確同向）
targetX = +mouse.x * 0.8
yaw = +mouse.x * 0.35
pitch = -mouse.y * 0.25
維度 / 行為 修正前錯誤根因 修正後正確向量公式
水平注視 (LookAt X) 誤將 targetX 乘上負號 -this.mouse.x，導致滑鼠在右眼球往左。 targetX = THREE.MathUtils.clamp(this.mouse.x * 0.8, -sin(MAX_YAW), sin(MAX_YAW))
頭部水平旋轉 (Yaw) 誤加負號 -this.mouse.x * 0.35，導致頭部與滑鼠方向相反轉動。 yaw = THREE.MathUtils.clamp(this.mouse.x * 0.35, -MAX_YAW, MAX_YAW)
頭部俯仰旋轉 (Pitch) 直接傳遞 +this.mouse.y，而 Three.js 骨骼 X 旋轉正值為低頭，造成滑鼠往上頭卻低下。 pitch = THREE.MathUtils.clamp(-this.mouse.y * 0.25, -MAX_PITCH, MAX_PITCH)
