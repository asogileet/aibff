🔬 擺臂相位與手肘軸向分析

❌ 原本的問題點
  • 擺臂方向相反：手臂擺動正負號反了，導致變成「同手同腳」（左腳往前時左手也往前，或左腳往前時右手向後）。
  • 手肘向外翻扭曲：原本誤用了 lowerArm.rotation.y = 1.15，繞 Y 軸旋轉導致小臂像翅膀一樣向側邊外翻，而不是真實跑步時手肘屈曲向前的狀態。
✅ 修正後的正確人體力學
  • 對側交叉平衡（Contralateral）：
    當左腿向前抬起（leftUpperLeg.rotation.x > 0）時，右手臂向前擺動（rightUpperArm.rotation.x > 0），左手臂向後擺動。
  • 前方屈肘 90°（Elbow Flexion）：
    改為 lowerArm.rotation.x = 1.35（繞 X 軸向前屈曲），小臂保持直立向前，手腕自然微收。

📐 修正後的運動學計算公式 

const swing = Math.sin(this.actionTime * 12.0);

// 雙腿交替大跨步向前/向後
leftUpperLeg.rotation.x  =  swing * 0.75;
rightUpperLeg.rotation.x = -swing * 0.75;

// 手臂對側反向擺動：左腿向前時，右臂向前 (+)、左臂向後 (-)
leftUpperArm.rotation.x  =  swing * 0.65;   // <-- 相位反轉修正！
rightUpperArm.rotation.x = -swing * 0.65;   // <-- 相位反轉修正！

// 手肘自然向前屈曲 90 度，取代原本的外翻 Y 軸
leftLowerArm.rotation.set(1.35, 0, 0);      // <-- 前屈肘修正！
rightLowerArm.rotation.set(1.35, 0, 0);     // <-- 前屈肘修正！
