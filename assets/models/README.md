# VRM 角色模型放置目錄

請將您的 VRM 3D 角色模型檔案命名並放置於本目錄：

1. `costume_casual.vrm` - 日常休閒服裝
2. `costume_school.vrm` - 青春水手服
3. `costume_stylish.vrm` - 優雅時尚服裝
4. `costume_gothic.vrm` - 哥德蘿莉風格
5. `costume_seed.vrm` - 未來科技裝 (Seed)

> **小提示**：系統已內建 Procedural 代理渲染機制。若尚未放入實體 `.vrm` 檔案，系統仍會自動生成具備標準骨骼與 BlendShape 映射的 3D 虛擬角色，各項呼吸、眨眼、摸頭、滑鼠眼神跟隨與即時口型同步功能皆可立即完整運作！
